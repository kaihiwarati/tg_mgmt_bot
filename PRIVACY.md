# Privacy Policy for Avikuxbot

**Last updated:** September 19, 2026

This Privacy Policy describes how **Avikuxbot** ("the Bot", "we", "us") collects, uses, stores, and protects information when you interact with it on Telegram.

By using the Bot, you agree to the practices described in this policy.

---

## 1. Who We Are

Avikuxbot is a Telegram group management bot operated by its owner. It provides moderation, filters, greetings, AFK tracking, fun commands, games, and other utilities for Telegram groups.

Contact: [@your_telegram_username]

---

## 2. What Data We Collect

The Bot collects and stores the following types of data:

### 2.1 Chat Data
- Telegram chat IDs (to identify which group a setting applies to)
- Chat titles (only when logging moderation actions, if a log channel is configured)

### 2.2 User Data
- Telegram user IDs (for warnings, AFK status, votes, admin actions)
- First names (used only for display in replies)
- Usernames (only when a command explicitly references them)

### 2.3 Message Content
- **Filters:** If a group admin creates a filter, the bot stores the associated keyword and response (text, photo, GIF, video, sticker, or voice message). Messages are only stored when an admin explicitly saves them as a filter.
- **Games:** Votes in Would You Rather games are stored temporarily to display results.
- **AFK:** The reason you provide when setting AFK status is stored until you return or manually clear it.

### 2.4 Moderation Logs (optional)
If the group operator has configured a log channel, the Bot may send moderation actions (bans, kicks, mutes, warns) to that channel. These logs contain:
- The action performed
- The Telegram ID of the acting admin
- The Telegram ID of the affected user
- The chat where it occurred
- A timestamp

### 2.5 What We Do NOT Collect
- Phone numbers
- Email addresses
- Passwords
- Private messages between users
- Payment information
- Location data

---

## 3. How We Use Your Data

Data collected is used exclusively to:
- Provide the Bot's features (moderation, filters, greetings, games, AFK, etc.)
- Enforce group rules set by admins (warnings, locks, anti-flood)
- Display relevant information when you or an admin runs a command
- Maintain state between sessions (e.g., remembering your AFK status)

Data is **never sold, rented, or shared with third parties** for marketing or any other purpose.

---

## 4. Data Storage and Security

- All data is stored in a **local SQLite database** on the server that hosts the Bot.
- The database is not exposed to the public internet.
- Access is restricted to the Bot's owner.
- Data persists across restarts and is retained until:
  - An admin removes the relevant filter, warning, or setting
  - The Bot is removed from a group (some per-chat data may remain until manually cleared)
  - You request deletion (see Section 6)

We take reasonable measures to protect your data, but no system is 100% secure. We cannot guarantee absolute security.

---

## 5. Data Sharing

We do not share your data with any third parties, except:
- **Telegram:** The Bot communicates with the Telegram API to operate. Telegram's own privacy policy applies to that communication.
- **Legal requirements:** If required by law, we may disclose data to authorities.

The Bot does not use external analytics, tracking, or advertising services.

## 6. Your Rights

You have the right to:
- **Access:** Ask what data the Bot holds about you.
- **Deletion:** Request that your data be deleted.
- **Correction:** Request corrections to any inaccurate data.
- **Withdrawal:** Stop using the Bot at any time. Removing the Bot from your group ends data collection for that group.

To exercise these rights, contact the Bot owner at **[@your_telegram_username]**.

Requests will be handled within a reasonable timeframe.
